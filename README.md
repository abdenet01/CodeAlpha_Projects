# Hangman Game - Python Project
## 📌 Description
This is a classic **Hangman game** implemented in Python.  
The game selects a secret word, and the player tries to guess it letter by letter.  
Incorrect guesses reduce the player's chances, and the game continues until the word is guessed or the player runs out of attempts.

This project demonstrates **Python programming**, **loops**, **conditional statements**, and **user interaction**.
## 🚀 Features
- Randomly selects a secret word
- Allows the player to guess letters one at a time
- Tracks correct and incorrect guesses
- Displays the current state of the word
- Ends game with a win or loss message
## 🛠 Technologies Used
- Python
- `random` module (to select words)
- `string` and basic Python functions
- Loops and conditional logic
